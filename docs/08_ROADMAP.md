## MVP v0.1

La prioridad del MVP será administrar clientes y registrar sus pagos.
Las funciones de monitoreo de red, inventario, integraciones y
documentos avanzados se desarrollarán después de validar el núcleo
administrativo.

La primera interfaz operativa de consulta ya comenzó después de estabilizar los
flujos principales, autenticación, permisos, procesos diarios y notificaciones.
Consume reglas probadas de la API y no duplica lógica de negocio. Las acciones
de escritura se incorporarán por módulo sólo cuando puedan conservar todas las
validaciones y evidencias del backend.
