# Identidad visual de Aether

Esta carpeta conserva la referencia original y las variantes optimizadas del
logotipo. La marca maestra es `aether-mark.png`, con fondo transparente.

## Uso recomendado

| Archivo | Uso |
| --- | --- |
| `aether-mark.png` | Marca principal sobre fondos neutros |
| `aether-app-icon-dark.png` | Aplicación, acceso directo y avatar oscuro |
| `aether-app-icon-light.png` | Aplicación o avatar sobre interfaces claras |
| `aether-horizontal-on-dark.png` | Encabezados, portadas y diapositivas oscuras |
| `aether-horizontal-on-light.png` | Documentos y diapositivas claras |
| `aether-horizontal-transparent-dark.png` | Firma sobre fondos claros personalizados |
| `aether-horizontal-transparent-light.png` | Firma sobre fondos oscuros personalizados |
| `aether-lockup-dark.png` | Portada cuadrada o publicación |
| `aether-mark-white.png` | Grabado o impresión monocromática sobre fondo oscuro |
| `aether-mark-ink.png` | Impresión monocromática sobre fondo claro |

## Reglas básicas

- No deformar, rotar ni cambiar las proporciones del símbolo.
- Mantener alrededor un espacio libre mínimo equivalente al 15 % de su ancho.
- Usar el símbolo solo a partir de 24 px; debajo de ese tamaño pierde detalle.
- Preferir la firma horizontal desde 240 px de ancho.
- No colocar la versión azul sobre fondos con poco contraste.
- Para impresión de una sola tinta, usar exclusivamente las variantes blanca
  o tinta.

## Paleta

- Azul noche: `#020D22`
- Tinta: `#071426`
- Azul Aether: `#168AF5`
- Azul luminoso: `#52B6FF`
- Blanco suave: `#F5F8FC`

Las variantes rasterizadas pueden regenerarse con `generate_variants.py`. El
archivo `aether-brand-reference.png` conserva la lámina visual recibida como
referencia y no debe publicarse como logotipo final.
